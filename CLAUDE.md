# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project state

ExamCards is a Unity 2D project (Unity `6000.6.3f1`, URP 2D renderer) that is still essentially the stock 2D URP template. There is no game code yet. The only C# under `Assets/` is the template's `Assets/Welcome/Welcome2DScript.cs` (tutorial/welcome page, assembly `Unity.2D.Welcome`), and the only scene is `Assets/Scenes/SampleScene.unity`. Update this file once real gameplay or architecture exists.

## Building and running

There is no CLI build, lint, or test setup in the repo. Work happens in the Unity Editor (version in `ProjectSettings/ProjectVersion.txt`). The `.sln`/`.csproj` files at the root are generated by the IDE integrations (Rider/VS/VS Code) and should not be edited by hand.

- Tests: `com.unity.test-framework` is installed, but no test assemblies exist yet. Run tests from Window > General > Test Runner. Batch mode would be `Unity.exe -batchmode -projectPath . -runTests -testPlatform EditMode -logFile -`.
- Input: the new Input System (`com.unity.inputsystem`) is used, with actions defined in `Assets/Settings/InputSystem_Actions.inputactions`.
- Rendering: URP assets and the 2D renderer are in `Assets/Settings/` (`UniversalRP.asset`, `Renderer2D.asset`).
- UI: uGUI (`com.unity.ugui`) and UI Toolkit modules are both enabled. The AI Assistant, AI Inference, Visual Scripting, and Timeline packages are also in `Packages/manifest.json`.

## Conventions for editing

- Every file and folder under `Assets/` has a paired `.meta` file holding its GUID. Never delete or recreate a file without its `.meta`. Move or rename files so the `.meta` goes with them, ideally inside the Editor.
- Scenes, prefabs, and `.asset` files are YAML text and can be diffed, but are normally edited in the Editor. Avoid hand-editing them.
- `Library/`, `Temp/`, `obj/`, `Logs/`, and `UserSettings/` are generated and should not be touched or committed.
